اربط المشروع بفايربيس أولاً

  1. افتح Firebase Console وأنشئ مشروع.
  2. فعّل Authentication → Email/Password، وأنشئ حساب أدمن.
  3. أنشئ Firestore Database و Storage.
  4. انسخ إعدادات الويب إلى js/firebase-config.js.
  5. انسخ قواعد firestore.rules و storage.rules داخل الكونسول، أو انشرها بـ Firebase CLI.
